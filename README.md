# MovieApp
An Compose Multiplatform app I wrote to learn new skills and exercise old skills, thanks to other open source apps I learnt from. This app is written in Kotlin and Compose Multiplatform, utilizing new Android Jetpack features such as Navigation, Room Persistence and Viewmodel Libraries extensively. Also, libraries such as Ktor and Coil are used. All movie data and images come from The Movie Database API.
